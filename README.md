# Cashio

اپلیکیشن مدیریت شخصی درآمد و هزینه با تمرکز بر سادگی، حریم خصوصی، حالت آفلاین و حالت ابری.

## نسخه انتشار
- نسخه: **1.6.0**
- Android application ID: `com.dakhlkharj.man`
- برند: **Cashio**
- رابط کاربری: فارسی، English، Русский، العربية، Türkçe
- ارزها: تومان، ریال ایران، USD، EUR، GBP، RUB، TRY، AED، SAR، CNY، JPY، CAD، AUD، CHF
- دو حالت داده: **Offline** و **Cloud**
- هر تراکنش ارز مستقل خودش را نگه می‌دارد و ارزهای مختلف بدون نرخ معتبر با هم جمع نمی‌شوند.
- حالت آفلاین بدون حساب کاربری قابل استفاده است.
- حالت ابری با ایمیل/جیمیل، رمز عبور و تأیید کد ایمیلی کار می‌کند.
- داده‌های ابری برای هر کاربر با RLS جدا می‌شوند.
- Web/PWA پس از اولین بارگذاری قابلیت کار آفلاین دارد؛ حالت Cloud برای احراز هویت و همگام‌سازی به اینترنت نیاز دارد.
- پشتیبان JSON و خروجی CSV دارد.
- حذف اطلاعات محلی و حذف اطلاعات ابری در حالت Cloud پشتیبانی می‌شود.

## امکانات
ثبت، ویرایش، حذف و جست‌وجوی تراکنش‌ها، دسته‌بندی‌های پیش‌فرض و سفارشی، فیلتر تاریخ/نوع/دسته/ارز، گزارش‌های مالی، نمودار، حالت روشن/تاریک/سیستم، پشتیبان و بازیابی، انتخاب زبان و ارز، و انتخاب محل نگهداری اطلاعات.

## ابر و حساب کاربری
برای راه‌اندازی بخش Cloud از `CLOUD_SETUP.md` و `supabase/schema.sql` استفاده کنید.

در Signup کاربر ایمیل/Gmail و رمز عبور می‌سازد و کد تأیید به همان ایمیل ارسال می‌شود. بعد از تأیید، با ایمیل و همان رمز عبور وارد می‌شود.

## انتشار تجاری
نسخه Android با امضای Release به صورت APK و AAB ساخته می‌شود. برای Google Play، فایل AAB نسخه Release استفاده می‌شود.

مدل درآمدی می‌تواند فروش خود برنامه در Google Play یا مدل‌های بعدی Freemium باشد. تنظیم قیمت، کشورها، حساب ناشر و انتشار Production از داخل Play Console انجام می‌شود.
