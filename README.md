# دخل‌وخرج من

اپلیکیشن شخصی مدیریت درآمد و هزینه با تمرکز بر آفلاین‌بودن، حریم خصوصی و چندارزی بودن.

## نسخه نهایی
- نسخه: **1.1.0**
- شناسه اندروید: `com.dakhlkharj.man`
- زبان‌های رابط کاربری: فارسی، English، Русский، العربية، Türkçe
- ارزهای اصلی: تومان، ریال ایران، USD، EUR، GBP، RUB، TRY، AED، SAR، CNY، JPY، CAD، AUD، CHF
- هر تراکنش ارز مستقل خودش را دارد.
- ارزهای مختلف هرگز بدون نرخ معتبر با هم جمع نمی‌شوند.
- تبدیل خودکار نرخ ارز وجود ندارد؛ بنابراین گزارش‌های مالی دچار تبدیل ساختگی یا نرخ کهنه نمی‌شوند.
- اطلاعات اصلی محلی نگهداری می‌شود و برنامه برای قابلیت‌های مالی اصلی حساب کاربری یا سرور اختصاصی لازم ندارد.
- Web/PWA پس از اولین بارگذاری قابل استفاده آفلاین است.
- Android با Manifest سخت‌گیرانه و بدون مجوز مؤثر INTERNET برای قابلیت اصلی بسته‌بندی شده است.
- پشتیبان JSON نسخه 2 دارد و پشتیبان نسخه 1 قبلی نیز مهاجرت می‌شود.
- خروجی CSV شامل کد ارز و داده‌های تراکنش است.
- حذف همه اطلاعات با تأیید چندمرحله‌ای انجام می‌شود.

## امکانات
ثبت، ویرایش، حذف و جست‌وجوی تراکنش‌ها، دسته‌بندی‌های پیش‌فرض و سفارشی، فیلتر تاریخ/نوع/دسته/ارز، گزارش روزانه تا سالانه، نمودار، حالت روشن/تاریک/سیستم، پشتیبان و بازیابی، و انتخاب زبان و ارز پیش‌فرض.
