# Cashio

اپلیکیشن مدیریت شخصی درآمد و هزینه با تمرکز بر آفلاین‌بودن، حریم خصوصی و چندارزی بودن.

## نسخه انتشار
- نسخه: **1.3.0**
- Android application ID: `com.dakhlkharj.man`
- برند: **Cashio**
- رابط کاربری: فارسی، English، Русский، العربية، Türkçe
- ارزها: تومان، ریال ایران، USD، EUR، GBP، RUB، TRY، AED، SAR، CNY، JPY، CAD، AUD، CHF
- هر تراکنش ارز مستقل خودش را نگه می‌دارد و ارزهای مختلف بدون نرخ معتبر با هم جمع نمی‌شوند.
- برنامه برای قابلیت‌های اصلی مالی بدون حساب کاربری و بدون سرور اختصاصی طراحی شده است.
- نسخه Web/PWA پس از اولین بارگذاری، قابلیت کار آفلاین دارد.
- نسخه Android برای قابلیت‌های مالی اصلی به اینترنت وابسته نیست و مجوز مؤثر INTERNET ندارد.
- پشتیبان JSON نسخه 2 و خروجی CSV دارد.
- حذف کامل داده‌ها با تأیید چندمرحله‌ای انجام می‌شود.
- کارت‌های صفحه خانه واقعاً قابل جابه‌جایی هستند و اطلاعات هر کارت همراه خود کارت جابه‌جا می‌شود.

## امکانات
ثبت، ویرایش، حذف و جست‌وجوی تراکنش‌ها، دسته‌بندی‌های پیش‌فرض و سفارشی، فیلتر تاریخ/نوع/دسته/ارز، گزارش روزانه تا سالانه، نمودار، حالت روشن/تاریک/سیستم، پشتیبان و بازیابی، انتخاب زبان و ارز، و شخصی‌سازی کارت‌های صفحه خانه.

## انتشار تجاری
نسخه Android با امضای Release به صورت APK و AAB ساخته می‌شود. برای انتشار رسمی در Google Play، فایل **AAB** نسخه Release مناسب است.

مدل درآمدی آماده این نسخه: **فروش خودِ اپلیکیشن به صورت Paid App در Google Play**، بدون تبلیغات و بدون فروش داده کاربر. قیمت، کشورهای عرضه و وضعیت Paid/Free باید در Play Console تنظیم شوند؛ این بخش از داخل کد قابل تنظیم نیست.

طبق الزامات فعلی Google Play در سال 2026، اپلیکیشن‌های جدید و به‌روزرسانی‌ها باید Android 16 / API 36 یا بالاتر را هدف بگیرند؛ پروژه در حال حاضر targetSdkVersion 36 دارد.
