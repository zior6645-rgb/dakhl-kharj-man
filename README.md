# Cashio

اپلیکیشن ساده و کاربردی مدیریت دخل‌وخرج شخصی با تمرکز بر حریم خصوصی و کارکرد آفلاین.

## نسخه انتشار
- نسخه: **1.7.0**
- Android application ID: `com.dakhlkharj.man`
- برند: **Cashio**
- رابط کاربری: فارسی، English، Русский، العربية، Türkçe
- ارزها: تومان، ریال ایران، USD، EUR، GBP، RUB، TRY، AED، SAR، CNY، JPY، CAD، AUD، CHF
- داده‌های مالی برای قابلیت اصلی روی خود دستگاه نگهداری می‌شوند و برای کارکرد اصلی حساب کاربری یا سرور لازم نیست.
- پشتیبان JSON و خروجی CSV دارد.

## امکانات
ثبت، ویرایش و حذف تراکنش‌ها، دسته‌بندی‌های پیش‌فرض و سفارشی، جست‌وجو و فیلتر، گزارش‌های مالی، نمودار، حالت روشن/تاریک/سیستم، انتخاب زبان و ارز، پشتیبان‌گیری و بازیابی.

هر تراکنش ارز مستقل خودش را نگه می‌دارد و ارزهای مختلف بدون نرخ معتبر با هم جمع نمی‌شوند.

## انتشار تجاری
نسخه Android با APK و AAB امضاشده Release ساخته می‌شود. برای Google Play از AAB نسخه Release استفاده می‌شود.

مدل درآمدی فعلی می‌تواند فروش خود برنامه در Google Play باشد. تبلیغات و analytics برای قابلیت اصلی برنامه ضروری نیستند.
